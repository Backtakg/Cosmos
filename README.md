# Cosmos College — Website Redesign Concept

An independent, responsive redesign concept for Cosmos College of Management and Technology, Kathmandu.

## Design direction

The experience combines:
- Editorial storytelling and research-style content hierarchy inspired by MIT.
- Clear audience pathways and navigation patterns informed by Stanford.
- Prominent academic program discovery inspired by Imperial College London.
- Bold, responsive visual presentation informed by University of Hull.

## Built with

- Semantic HTML
- CSS custom properties and responsive layouts
- Vanilla JavaScript
- Google Fonts (Manrope and DM Sans)
- Illustrative photography from Unsplash

No framework, build step, paid service, database, or API key is required.

## Run locally

Open `index.html` in a browser, or serve the repository with any static file server.

## Deploy with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **GitHub Actions**.
3. Push to `main`; the included workflow publishes the site.

## Important prototype notes

- This is an independent redesign concept, not the official Cosmos College website.
- Program names, seat counts, affiliation, location and contact details are based on information publicly published by the college and should be reconfirmed by the institution before production use.
- Images are illustrative and should be replaced with approved campus, faculty, laboratory and student photography.
- The enquiry form prepares an email in the visitor's email application. It does not store or transmit submissions to a backend.
- No admission, ERP, payment, student portal or college system integration is implemented.
